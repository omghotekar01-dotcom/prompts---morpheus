# MORPHEUS Engineering Bible

This repository is the canonical prompt/specification pack for building MORPHEUS: a workload-aware, hardware-aware physical data-structure synthesis and adaptation system.

## Start here
For a capable coding/research AI, read in this order:
1. `AI-START-HERE.md`
2. `prompts/30-grand-master.md`
3. `MASTER-INDEX.md`
4. Specialized prompt volumes relevant to the current milestone.
5. `FINAL-CHECKLIST.md` before claiming completion.

## Repository purpose
These files define architecture, mathematics, MWS/IR, primitive ecosystem, cost modelling, search, code generation, correctness, benchmarking, runtime adaptation, backend/UI/AI, research/IP, production, testing, product, documentation, execution roadmap and final audit/release.

## Important
The prompt pack is a blueprint, not proof that the software is implemented. Any implementation must distinguish PROPOSED, IMPLEMENTED, TESTED, MEASURED and VALIDATED states. No benchmark, novelty, patent or completion claim should be made without evidence.

## Storage policy
Keep this repository lightweight: Markdown/specification text and small fixtures only. Do not commit generated binaries, large datasets, traces, calibration dumps, screenshots/PDF duplicates or model artifacts. Store large reproducible artifacts elsewhere by checksum/reference.
