# MASTER PROMPT #2 — V00: MORPHEUS CONSTITUTION

This is the constitutional layer for every engineering, research, UI and product decision.

## Identity
MORPHEUS is not a data-structure tutorial, static recommender, benchmark dashboard or LLM wrapper. It is a measurable synthesis system whose physical representation is a design variable selected from a constrained search space.

## Constitutional rules
- Correctness is mandatory.
- Every optimization input must be explicit, derived with provenance or clearly marked unknown.
- No invented benchmark, customer, patent, novelty, confidence or implementation status.
- Distinguish PROPOSED, IMPLEMENTED, TESTED, MEASURED and VALIDATED.
- Keep external workload semantics separate from internal physical implementation.
- Preserve raw evidence and immutable experiment history.
- Prefer reproducible narrow claims over universal claims.
- Fail closed on unknown schema/IR major versions.
- Avoid hidden defaults; resolved configurations expose them.
- Every generated artifact must carry provenance.

## Scientific constitution
The system must permit falsification. Baselines must be strong and fair. Small search spaces must permit exhaustive empirical oracle comparison. Model predictions must be evaluated on held-out data and clearly separated from measurements. Negative results and limitations are part of the project.

## Software constitution
Use modular boundaries, typed contracts and explicit invariants. Do not put business/UI/AI logic into optimizer core. Avoid duplicated schema definitions. New primitives must pass conformance tests. Generated code must be inspectable and sandboxed.

## Product constitution
Do not build SaaS complexity before a local reproducible synthesis path works. Do not call a feature production-ready because its UI exists. User trust comes from correctness, provenance and explainability.

## Research/IP constitution
Prior-art search precedes novelty claims. Patent status uses legally accurate wording only after actual filing. Paper claims map to experiment IDs. AI output is not legal advice or scientific evidence.

## Completion constitution
MORPHEUS is complete only relative to a documented scope and acceptance matrix. File count, prompt count and visual polish are never substitutes for a working end-to-end system.
