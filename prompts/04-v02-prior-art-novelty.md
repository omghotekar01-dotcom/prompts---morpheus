# MASTER PROMPT #4 — V02: PRIOR ART, NOVELTY & RESEARCH POSITIONING

Map MORPHEUS against existing ideas before making originality claims.

## Search domains
Investigate database physical design/advisors, learned indexes, adaptive indexing, auto-tuning, self-driving databases, compiler autotuning, program synthesis, data-structure synthesis, hardware-aware structures, composite indexes, workload forecasting/adaptation, benchmark-driven optimization and generated code systems.

## Method
Search by mechanism, not only by project name. For every source record: bibliographic/patent identifier, date, problem, mechanism, optimization variables, workload representation, hardware awareness, generated output, runtime adaptation, evaluation and exact overlap/difference.

## Novelty matrix
Rows represent MORPHEUS candidate mechanisms; columns prior systems. Classify SAME/PARTIAL/DIFFERENT/UNKNOWN with evidence. Focus on combinations of mechanisms rather than claiming every component is individually new.

## Positioning discipline
Use phrases such as "we investigate", "we combine", "we extend", or "we did not identify in our search" until evidence supports stronger language. Never infer nonexistence from a limited search.

## Comparison axes
Input granularity; DSA-level vs DB-level physical design; single vs composite structures; machine calibration; empirical vs analytical model; constrained multi-objective search; executable code generation; correctness verification; runtime transition-aware adaptation; provenance/reproducibility.

## Research gap output
Write the narrowest defensible gap statement. Example form: existing systems address A/B/C, while MORPHEUS studies whether X+Y+Z at the application data-structure layer can be synthesized and empirically validated under explicit workload/hardware constraints. Treat this as a hypothesis until review is complete.

## Patent search
Search relevant CPC/IPC terms and patent families for the technical combination. Record claims/figures relevant to synthesis, autotuning and adaptive physical structures. Patent counsel determines legal novelty/non-obviousness.

## Deliverable
Produce related-work taxonomy, source table, novelty matrix, gap hypotheses, terminology alignment, patent-search log and a list of claims that are unsafe until further evidence. Update this volume before any submission because prior art changes.
